# Food Plaza — Bettiah

A responsive editorial restaurant website for Food Plaza on Supriya Road, Bettiah.

## Stack
- React + TypeScript
- Vite
- Vitest
- Lucide icons
- CSS with responsive layouts

## Development
```bash
npm install
npm run test
npm run build
npm run dev
```

## Data note
Business details are based on public listings. The site intentionally does not hard-code a phone number because public sources currently show conflicting numbers. Menu items shown are a small verified set; the live ordering menu is linked for current availability and pricing.

## Asset note
The hero imagery is a public listing image reference used for the design prototype. Confirm image reuse/licensing with the business before commercial publication.
